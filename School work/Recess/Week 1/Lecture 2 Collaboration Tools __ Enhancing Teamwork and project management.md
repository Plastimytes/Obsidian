**Tools**:: Google drive, Google Docs, Slack, Canva and Trello

Why does these tools matter?
 Enhance productivity
 Streamline workflows
 Improve team coordination
**Google Drive**
 Use cases- Team file sharing. Centralized storage for group projects. Back up of important docs
**Google Docs**
 An online word processor for creating and editing documents collaboratively.
 **Key Features:** Real time editing. Commenting and suggesting. Automatic saving.
 **Use cases:** Brain storming ideas. Drafting shared documents. Collaborative reports
**Slack**
 Comm. platform that organizes team conversations into channels and allows direct messaging.
 **Key Features:** Channels for team topics. File sharing and integration. Notifications and reminders.
 **Use Cases:** Keeping team discussions organized. Sending quick updates and reminders. Sharing files and links.
**Canva**
 Graphic design platform for creating visual content such as posters, presentations, and social media posts.
 Key Features: Ready-to-use templates. Collaborative design tools. Easy Sharing options.
 Use Cases: Designing team presentations. Creating social media graphics.
**Figma**
 Collaborative web-based design tool used for UI/UX design, prototyping and wireframing.
 **Key Features**: Real-time collaboration on designs. Cloud-based storage for easy access. Plugins for design automation.
 **Use Cases:** Designing user interfaces and wireframes. Prototyping apps and websites. Collaborative brainstorming using Fig jam.
**Trello**
 A project mgt. tool that uses boards, lists and cards to organize tasks visually.
 **Key Features:** Drag and drop task management. Assigning tasks and setting  deadlines. Adding labels, checklists, and files.
