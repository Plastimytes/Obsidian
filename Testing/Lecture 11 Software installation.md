Tools: BIOS setup
We learned about the components of the Bios setup which gave the system information, Processor information, Memory Information, PCI information, Date/Time, Boot Sequence, Security, Power management and a few others. After that we where guided on how to download an operating system through downloading the ISO image to a flash drive that must be empty and one must use rufus to make it a bootable drive. In task manager you can see the computer's performance and activity

Learn insights: A computer does not necessarily need an Operating system to boot up and the BIOS gives the relevant information about the computer system. You can change the computer's performance enable and disable peripheral devices in the BIOS under the drives section. ISO images are the way to get operating systems onto other computers. Remember to read the application notices and license terms. If software is licensed it means that it's rented out to you. In the task manager you can see the performance of the computer system.
